# Governance IA
Guida indipendente realizzata da Gianluigi Cogo, consulente, formatore e divulgatore · 9 novembre 2026.

## Aprire la guida sul computer
Estrai lo ZIP e apri index.html nel browser. La cartella contiene la home, sei capitoli, due infografiche, la ricerca, gli stili, la copertina, i caratteri con la loro licenza e le tre analisi in PDF.

## Pubblicare su GitHub Pages
1. Accedi a GitHub e crea un repository pubblico, ad esempio governance-ia.
2. Nella pagina del repository seleziona il collegamento per caricare file oppure Add file → Upload files.
3. Apri la cartella estratta e trascina tutto il suo contenuto nella finestra di caricamento, compresa la cartella fonts. Verifica che index.html sia al primo livello, accanto ai tre PDF.
4. Seleziona Commit changes per salvare i file nel ramo main.
5. Apri Settings → Pages. In Build and deployment scegli Deploy from a branch, poi main e /(root). Premi Save.
6. Al termine della pubblicazione, torna in Settings → Pages e apri Visit site.

## Verificare la pubblicazione
Apri un capitolo, cerca PIAO, visita entrambe le infografiche e apri i tre allegati dalla sezione Fonti. Mantieni i nomi dei file e le maiuscole per conservare i collegamenti.

[Documentazione di GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
